# Neymar I.A
🤖 Assistente virtual desenvolvido em Python como projeto pessoal de aprendizado, utilizando conhecimentos de lógica de programação e integração com novas bibliotecas e APIs. O projeto foi desenvolvido com auxílio de tutoriais e IA, permitindo aprender na prática sobre reconhecimento de voz, síntese de voz, integração com Inteligência Artificial e programação em Python.
